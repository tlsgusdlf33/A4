# 신규 프로젝트 폴더 발생 시 — 펌프 선정 및 4종 도서 작성 (최우선 업무)

`01 도서 / <연도> / ` 아래에 새 프로젝트 폴더가 생기면 즉시 착수한다.

## 1단계 — 사양 확보

`<프로젝트>/# spec 정리` 에서 다음을 읽는다.

- `Att.#6_…기술규격서_Rev.x(For MR).pdf` — 주 사양서
- `Att.#2_Shop Inspection and Test Procedure.pdf` — 시험 범위(성능/NPSH/수압)
- `Att.#3_Packing`, `Att.#4_Shipping`, `Att.#5_Vendor Supervision`, `Att.#1_General Terms`
- 발주처 배치도(`…ENLARGED PLAN…DWG`, `…장비기초 상세도.dwg`) — 설치 공간/기초 제약

### 사양서에서 반드시 뽑아낼 항목

| 구분 | 항목 |
| --- | --- |
| 유체 | 종류, 온도(정격/최대), 비중, 점도, 증기압, 고형물 |
| 운전점 | 정격 유량, 정격 양정, 최소/최대 유량, 병렬 운전 여부 |
| 흡입 | NPSHa, 흡입 압력(정격/최대), 흡입 수위, Can 필요 여부 |
| 계통 | 토출 압력, 설계압력, 허용 최대 차단양정, 재순환 유량 |
| 구조 | 형식(수평/수직, 단단/다단), API 610 / ANSI / KS, 타입 코드(OH/BB/VS) |
| 재질 | 케이싱 / 임펠러 / 샤프트 / 웨어링 |
| 실 | 메커니컬 실 규격(API 682 plan), 제작사 |
| 구동 | 모터 정격, 전원, 방폭, 절연/보호등급, 커플링 형식 |
| 부속 | Cooler, Strainer, PSV, LCP, 연료탱크(엔진 구동 시) |
| 시험/도장 | 시험 항목, 도장 사양, 소음, 진동 기준 |
| 일정 | 도서 제출 일정(T-xx), 납기 |

## 2단계 — 펌프 모델 선정

1. 정격 유량·양정을 사내 선정선도에 투영해 후보 모델 2~3개 도출.
2. 후보별로 확인:
   - 정격점 효율, BEP 대비 운전점 위치(권장 70~120%)
   - NPSHr < NPSHa − 여유(통상 0.6 m 또는 1.35배 중 큰 값)
   - 차단양정 및 상승곡선 형상(발주처 상한 조건 충족 여부)
   - 최소연속안정유량(MCSF) < 요구 최소 유량
   - 축 강성(L³/D⁴), 웨어링 재질 조합, 실 챔버 압력
   - 모터 축동력 여유(비과부하 특성 또는 정격 대비 110% 이상)
3. 선정 결과를 `00 성능곡선` 에 근거 자료와 함께 남긴다.
4. 모델 표기 예: `HB1510-250BH` (형식-흡입구경-임펠러경-단수/코드)

## 3단계 — 4종 작성

| 산출물 | 내용 | 보관 위치 |
| --- | --- | --- |
| **데이터시트** | 운전조건, 성능, 재질, 실/커플링, 모터, 시험·도장 항목을 발주처 양식(Att. 첨부 양식 우선)에 기입 | `# 제출/<회차>/# 도서` + `# pdf` |
| **성능곡선** | Q-H, Q-효율, Q-축동력, Q-NPSHr. 정격점·최소유량·차단점 표기, 임펠러 트림 표기 | `00 성능곡선` |
| **외형도(GAD)** | 평면·정면·측면, 흡입/토출 플랜지 규격·위치, 베이스플레이트/기초 볼트 배치, 전체 중량, 인양점 | `# 제출/<회차>` (dwg + pdf) |
| **조립도** | 단면 조립도, 부품번호·명칭·재질 리스트(BOM), 실 장착부 상세, 베어링/웨어링 클리어런스 | `# 제출/<회차>` (dwg + pdf) |

## 4단계 — 제출

1. 도번 부여 후 `<도번> <제목>_<모델>_Rev 0_<YYMMDD>` 로 명명.
2. `# 제출/<YYMMDD> T-xx/# 도서` 에 원본, `# pdf` 에 PDF 배치.
3. 기술 → 영업 제출 메일, 영업 → 발주처 제출 메일을 `# 메일` 에 `.msg` 로 보관.
4. VDRL(Vendor Document Requirement List) 대조하여 누락 항목 확인.
