# 점검 런북 — 매 회차 실행 순서

Google Drive MCP 도구 기준. `<LAST>` = 직전 점검 시각(RFC3339 UTC).

## 1. 신규 프로젝트 폴더 감지 (최우선)

```
search_files:
  mimeType = 'application/vnd.google-apps.folder'
    and parentId = '10ZY6eP8fz8qN7qQDd8d0CvAhgijnlyEN'
    and createdTime > '<LAST>'
```
결과가 있으면 → `docs/10_신규프로젝트_펌프선정_절차.md` 착수.
해당 폴더 하위 `# spec 정리` 를 `parentId = '<신규폴더ID>'` 로 조회해 기술규격서를 읽는다.

## 2. 신규 Outlook 메일 감지

```
search_files:
  mimeType = 'application/vnd.ms-outlook' and createdTime > '<LAST>'
  (excludeContentSnippets: true, pageSize: 100)
```
- 파일명 `<번호> <YYMMDD> <발신-수신> <요지>.msg` 를 파싱해 프로젝트별 번호순으로 정렬.
- 발신이 외부(발주처/벤더)이고 뒤에 `기술-<상대처>` 또는 `영업-<상대처>` 회신이 없으면 **미회신**.

## 3. 그 외 변경

```
search_files:
  createdTime > '<LAST>' and owner = 'me'
```

## 4. .msg 본문 읽기

`read_file_content` 는 `application/vnd.ms-outlook` 미지원.
`download_file_content` 로 base64 를 받고(대용량은 자동으로 파일 저장됨) 아래로 파싱한다.

```python
import json, base64, re, olefile     # pip install olefile
d = json.load(open(saved_json_path))
raw = base64.b64decode(d['content'])
open('m.msg','wb').write(raw)
ole = olefile.OleFileIO('m.msg')
for e in ole.listdir():
    m = re.match(r'__substg1\.0_([0-9A-F]{4})([0-9A-F]{4})', e[-1])
    if not m: continue
    tag, typ = m.groups()
    if typ != '001F': continue
    val = ole.openstream(e).read().decode('utf-16-le', 'ignore')
    # 0037 제목 / 0C1A 발신 / 0E04 수신 / 0E03 참조 / 1000 본문 / 3707 첨부파일명
```
